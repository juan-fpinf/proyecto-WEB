Presentación del módulo de Lenguajes de marcas

Este módulo tiene como objetivo enseñar a los estudiantes los fundamentos y las técnicas necesarias para crear y gestionar contenido web utilizando lenguajes de marcas como HTML y XML. A lo largo del curso, se explorarán conceptos clave, buenas prácticas y herramientas que permitirán a los estudiantes desarrollar sitios web funcionales y accesibles.

Objetivos del módulo

  • Comprender la estructura y sintaxis de HTML.
  • Aprender a utilizar etiquetas y atributos para crear contenido web.
  • Explorar el uso de CSS para el diseño y la presentación de páginas web.
  • Introducir conceptos básicos de accesibilidad web.
  • Fomentar la creatividad y la innovación en el desarrollo web.

Metodología de enseñanza

El módulo se impartirá mediante una combinación de clases teóricas, prácticas en laboratorio y proyectos individuales o en grupo. Se fomentará la participación activa de los estudiantes a través de ejercicios, debates y presentaciones.

Para el desarrollo de las actividades prácticas se utilizará Visual Studio Code (VS Code) como entorno principal de desarrollo. Los estudiantes aprenderán a crear, organizar y editar sus proyectos web utilizando esta herramienta.

Además, se utilizará GitHub para trabajar con repositorios de código. Los estudiantes aprenderán los conceptos básicos del control de versiones, así como a guardar, actualizar y compartir sus proyectos mediante repositorios GitHub.
